# matteoantoci-plugins

Claude Code marketplace for personal plugins.

## Install

In Claude Code:

```
/plugin marketplace add matteoantoci/claude-plugins
/plugin install google-slides-mcp@matteoantoci-plugins
```

Then run `/reload-plugins` if Claude asks.

## Plugins

- [google-slides-mcp](https://github.com/matteoantoci/google-slides-mcp): Google Slides MCP server.

This repository is the catalog. Each plugin lives in its own repository.
